# Message Broker

Транспорт событий `message.accepted` / `message.delivered` из outbox шардов в Analytics. Публикация только после коммита транзакции.

**Владелец:** клиент и учёт. Контракт с остальными — в [`docs/api.md`](../../docs/api.md).
