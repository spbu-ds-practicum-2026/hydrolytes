# SMTP Gateway

Принимает письма по SMTP от заглушки-отправителя и передаёт в Mail по внутреннему контракту `POST /internal/v1/inbound`. Отвечает `250 OK` только после сохранения письма, иначе `451`.

**Владелец:** ядро почты. Контракт с остальными — в [`docs/api.md`](../../docs/api.md).

## Статус

Каркас. Каталог создан; реализация — по задачам в `.github/ISSUE_TEMPLATE` и плану работ.
